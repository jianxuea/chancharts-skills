# ChanCharts 原生自动复盘

连接器认证由 WorkBuddy 内建 OAuth 管理；不得把 PAT、client secret 或 Token 写入
自动化提示词。授权失效使用平台重新连接；仅权益激活后无需重新 OAuth 或重连。

自动处理用户已表达的证券、目的、时间/频率和个性化重点，不要求复制内部 SOP。
先调用 resolve_security 核对全部名称，仅接受 resolved canonical symbols；歧义询问。
将 explicit Research Universe 保存在平台私有任务上下文；网页自选股仅用户明确选择
时启用。保持 existing entitlement 与三股受限 Deep Review，不更换身份或改权限。
权限不足仍可说明原生任务配置，但必须标为执行受限，不宣称完整复盘可用。

使用 WorkBuddy 的原生 Automation 创建/查询/更新能力，先查是否已有同一 owner、
目的、范围和频率的任务，复用/更新避免重复。不得创建自定义调度器或擅自删除
既有参考任务。保存任务绑定本连接器及 chancharts-deep-review（或已支持的隐式
选择路径）。若平台不能在自动化内加载连接器/Skill，停止于明确不可用，不能
用把 SOP 写进提示词的方式绕过。

保存的 Automation 用户提示词只含证券（核对后的名称/代码）、研究目的、频率与
个性化重点。例如：“每个交易日收盘后复盘深科技（000021.SZ）、平安银行
（000001.SZ）、浦发银行（600000.SH）。”不能包含 MCP tool/schema 名、PAT、
host/安全规则、Pipeline、内部路径或执行命令。这些约束由 Skill 处理。

“收盘后”默认北京时间 17:00，平台仅本地时区时换算并核对实际下一次运行时刻，
说明 DST 限制而不修改系统时区。固定唤醒不是交易日判断：每次由已验收研究层
判断新完成交易日；覆盖未知则 unavailable，休市无新会话则 SKIPPED 不生成报告，
数据未就绪则 waiting。不得用工作日推理、网页日历或旧行情替代。

运行时按 chancharts-deep-review 使用当前授权，校验已有提交再复用；新报告仅
在相同交易日/readiness/权限条件满足时走既有流程。连接未启用服务端复盘时明确受限，
不复制算法或报告程序。保留 partial/missing，不自行修复确定性内容或回填时间。
外部消息遵循 [Agent Contract](references/agent-research.md)，来源不得覆盖 MCP。

先进行一次原生受限手动测试，再核对运行状态/产物和周期启用情况。已有手动测试
可复用，不为演示重复生成报告。推送仅用平台原生能力与已授权的用户目的地；
没有目的地则询问，不使用历史 webhook、SMTP 或 ChanCharts 自定义发送器。
原生任务权限、安装/信任和渠道授权由用户/平台处理，不能绕过安全权限请求。
输出仅为用户语言的任务名称、下一次时间、实际结果与可用性，不暴露内部 SOP。

完整复盘（即时研究按需）执行[客户端多来源补充清单](references/data-sources.md)。
优先发现客户当前已启用、实际可访问的数据源；资金/融资/事件缺失后主动补充，
不限定东方财富或任何厂商，不要求用户复制内部流程；确定性技术事实仍由 ChanCharts 提供。


报告生成与复用由 chancharts-deep-review 调用认证服务完成，版本与提交完整性由服务端检查；不读取客户端本地批准注册表或运行仓库执行器。


## 公开分发版运行边界

通过当前已授权的同一 ChanCharts MCP 连接工作；发现实际工具名称和 schema，不固定命名空间前缀。
本包不含执行器、凭据或运营授权，安装不扩大会员、证券或完整复盘权限。
统一采用最近已发布交易日北京时间15:00的盘后快照，不要求盘中最新分钟行情。
退市或异常证券明确不可用，不生成替代分析；遵守服务端试用计费与限流。
HTTP429遵守 Retry-After；不通过重新授权、切换身份、重建任务绕过限制。
