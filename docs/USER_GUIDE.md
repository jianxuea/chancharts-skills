# ChanCharts × WorkBuddy 使用说明

想看一只股票的走势结构，却不想每天手动划线、翻资料？你可以把 ChanCharts 接到 WorkBuddy，然后像聊天一样提问，让它帮你查询、比较和整理复盘。

第一次使用，按这条顺序就好：**添加连接 → 浏览器同意授权 → 回到 WorkBuddy → 说出你想分析的股票。**

本文更新于 2026 年 10 月 26 日，面向使用 WorkBuddy 的用户。

## 1. 能帮你做什么？

- **看一只股票：**了解缠论结构、常用技术指标，以及值得继续观察的变化。
- **比较几只股票：**按相同角度整理差异，省去来回切换、手工对比的麻烦。
- **做复盘报告：**具备相应权限和配套技能时，生成包含图表的完整复盘。
- **安排定时复盘：**在 WorkBuddy 支持的任务功能中，设置固定时间跟踪你关心的股票。

ChanCharts 目前用于**盘后研究**，分析的是最近已经发布的收盘数据，不是实时行情。即使报告中有“1 分钟”图，也是在查看已发布交易日的历史分钟走势，不代表正在接收实时价格。

## 2. 第一次连接：复制配置，再点授权

### 第一步：打开 WorkBuddy 的自定义连接器

在 WorkBuddy 中找到“连接器”里的“自定义连接器”或“添加 MCP”。部分版本的入口在左侧“专家·技能·连接器”中，名称和位置可能略有不同。

MCP 可以简单理解为“让 WorkBuddy 使用 ChanCharts 的连接”。你不需要了解它的技术细节。

### 第二步：添加 ChanCharts

如果页面支持粘贴配置，完整复制下面这段内容：

```json
{
  "mcpServers": {
    "chancharts": {
      "type": "http",
      "url": "https://mcp.chancharts.com/mcp"
    }
  }
}
```

如果页面让你分别填写名称和地址，名称填 `chancharts`，地址填：

```text
https://mcp.chancharts.com/mcp
```

连接类型选择远程 HTTP；如果界面写的是“Streamable HTTP”，选择这一项。

**这个地址要填在 WorkBuddy 中，不是让你点击打开的介绍网页。** 不需要下载连接器 ZIP，也不需要填写 Token、密钥或 Authorization 请求头。首次免费体验不要求邀请码、密码或注册表单。

如果你已经有一个同名连接，不要再粘贴出第二个同名条目；先确认现有条目是否就是这个地址。请勿把旧连接的手工凭据复制到新配置里。

### 第三步：点击“连接”，在浏览器中同意

保存后，按页面提示启用连接，并点击“连接”。WorkBuddy 会打开 ChanCharts 授权页。

1. 确认授权页面来自 `mcp.chancharts.com`。
2. 阅读页面说明，点击“同意并继续”。
3. 如果浏览器询问是否允许返回 WorkBuddy，选择允许。
4. 如果页面显示“授权完成，可以关闭此页面”，回到 WorkBuddy 即可。
5. 在 WorkBuddy 中确认连接已完成，再开始提问。

这就是 OAuth 授权：由你在浏览器里同意连接，后续凭据由客户端管理，不需要手动复制。

**已经有 ChanCharts 网站账号的用户：**建议在已登录该账号的同一浏览器中完成授权，方便沿用原有身份和权益。网站仍按原有邀请码方式登录或激活；首次 MCP 免费体验不要求先登录网站。

### 第四步：发一句话，试试连接

在 WorkBuddy 对话中选择或启用 ChanCharts，然后发送：

> 请只用 ChanCharts 查询 600519 是哪只股票，告诉我名称和数据截至哪个交易日。

正常情况下，会得到“贵州茅台、600519.SH”等解析结果。**仅查询股票名称和代码不消耗分析次数。**

## 3. 开始分析：直接说你的问题

你不需要记工具名称，也不需要先把股票加入自选。直接说股票名称或代码即可；遇到名称有歧义时，先确认助手选的是哪一只。

下面几句话可以直接复制。

**快速了解一只股票**

> 请用 ChanCharts 分析深科技，先给我简洁结论，再说明技术结构、主要风险和数据截止日期。

**把几只股票放在一起比较**

> 比较深科技、平安银行和浦发银行的技术结构，整理各自值得继续观察的变化。缺少的数据请直接说明。

**按自己的关注点分析**

> 我更关注中期走势，请重点看日线和30分钟结构，短周期简要说明。只使用我有权限查看的内容。

**了解最近一次变化**

> 如果有可用的历史数据，请比较这只股票最近两个已发布交易日的结构变化；无法比较的部分不要推测。

**补充资金和公司事件**

> 除了技术结构，也帮我查一下资金变化和近期公司事件。请写清楚来源、日期；没有可靠数据的地方标注缺失。

报告里出现“买点”“卖点”等词，是对走势结构的描述，不是让你立即买卖的指令。

## 4. 免费体验怎么计算？

每个用户身份共有 **5 次免费分析体验**，不是发 5 条消息，也不是助手每查询一步就扣一次。

- 一次分析可能需要多步查询，同一分析内的多工具调用、重复请求和重试按既有规则合并计次。
- 分析不同股票分别计算；一次要求比较三只股票，可能消耗三次分析机会。
- 查询股票名称或代码不扣分析次数。
- 分析失败、没有可用结果或权限不足，不应消耗分析次数。
- 换连接、重新授权不会重新获得 5 次机会。

已有有效会员或相应 MCP 权益的用户，按当前权益使用，不消耗免费体验。**免费体验不等于所有功能都已开放**，网站自选股、完整复盘等功能还要看对应权限。

## 5. 体验用完后，怎么继续用？

如果提示“免费体验次数已用完”（有时显示 `TRIAL_EXHAUSTED`），说明连接仍然正常，只是需要开通后续权益。**不用删除连接，也不用重新授权。**

1. 在完成授权的同一浏览器中打开[会员升级与激活页面](https://chancharts.com/mcp/upgrade)。
2. 按页面说明了解知识星球加入方式，获取相应的有效激活邀请码。
3. 核对当前身份，按页面提示完成激活。如果页面要求确认身份，请先完成该步骤，避免把权益激活到其他账号。
4. 回到原 WorkBuddy 对话，再发起分析即可，不需要重新连接。

符合条件的邀请码可开通一年 MCP 权益。续期在当前有效到期时间上再加 365 天；如果已经到期，则从激活时开始计算。具体产品、有效期和可用功能以激活页面为准。

MCP 分析权益与网站会员功能分别判断。开通 MCP 不代表自动获得所有网站、自选股或完整复盘功能；原有网站会员也不会因此被改成另一个等级。

## 6. 想要带图表的完整复盘？

日常问答可以直接使用连接。**完整复盘还需要相应权限和配套的复盘技能**，仅连接成功不代表已经具备完整报告功能。

如果你的 WorkBuddy 已提供 ChanCharts 技能，可在对话中选用“ChanCharts 完整复盘”；安排定时报告时，再配合“自动复盘”技能。若技能列表中没有，请从 [ChanCharts Skills 官方仓库](https://github.com/jianxuea/chancharts-skills) 的 Releases 下载对应 ZIP，在 WorkBuddy 的“添加技能 → 上传技能”中分别导入。

准备好后，可以这样说：

> 请用 ChanCharts 给深科技做一份完整复盘，包含我有权限查看的图表，重点说明技术结构、主要风险和后续观察条件。资金或事件数据缺失时，请明确标注。

报告生成后，打开 WorkBuddy 返回的报告或附件，确认内容和图表可以查看。若提示没有完整复盘权限，可以先使用普通分析；若提示报告仍在生成，按助手提示继续查询原报告即可。

## 7. 想每天自动复盘？

先手动完成一次分析，确认连接、权限和报告交付都正常，再安排定时任务。

可以把这句话交给 WorkBuddy：

> 请帮我设置一个定时任务：每个交易日北京时间20:30，用 ChanCharts 复盘深科技和平安银行，突出相对上一交易日的变化。运行前检查最近已发布交易日；如果当日盘后数据尚未更新，请说明实际截止日期，不要当作今天的数据。请确认任务已创建，并告诉我在哪里查看结果。

定时复盘同样受你的分析次数和功能权限限制。任务创建后，到 WorkBuddy 的任务列表核对时间、执行内容和结果位置，先观察一次实际运行是否成功。

**本地任务需要电脑和 WorkBuddy 保持运行，且网络可用。** 如果电脑关机，不能默认它仍会执行。想用云端任务，需要先确认该平台支持 ChanCharts 连接、对应技能和报告交付。

ChanCharts 自身更新了行情，不等于已经替你建立个人复盘任务；个人任务仍需在 WorkBuddy 中设置。

## 8. 怎么看懂结果里的日期和缺失提示？

看报告时，先看“数据截至哪个交易日”，再看结论。报告生成于今天，不代表行情也更新到了今天。

ChanCharts 按最近已发布交易日的北京时间 **15:00 收盘**作为分析截止时点。当日盘后数据还没发布时，显示上一个已发布交易日是正常情况，不能把它当作实时行情。

| 看到的提示 | 怎么理解 |
| --- | --- |
| 数据完整 | 本次请求所需的数据齐备，仍要核对截止日期。 |
| 部分数据缺失 | 有些内容可用，有些没有；先看具体缺项，不要把缺失当作零。 |
| 数据较早 | 结果可能仍有参考价值，但不能当成最新行情。 |
| 暂无可靠数据或证券不可用 | 当前无法完成该项分析，请勿让助手编造结果。 |
| 权限不足 | 连接可能正常，但当前身份不能使用这项功能。 |

目前部分历史资金流和未来解禁信息可能缺失。助手可以使用你有权访问的其他可靠来源补充，但必须说明来源、日期和统计口径；拿不到就应明确写“缺失”，不能声称已经分析完整。

## 9. 连接或使用时遇到问题怎么办？

| 情况 | 建议处理 |
| --- | --- |
| 点击一个地址出现404 | 先确认用途：MCP服务地址要填入WorkBuddy，不是介绍网页；升级页面请使用本文给出的链接。仍有问题时，把不含凭据的地址发给支持。 |
| 显示“需要认证”或 `Needs authentication` | 点击该连接的“连接”，完成浏览器授权；若没有打开网页，核对地址并检查是否被浏览器拦截。 |
| 浏览器显示“授权完成”，客户端还在授权中 | 先回到WorkBuddy查看；若浏览器询问是否允许返回客户端，选择允许。仍未完成时保留现场，联系支持。 |
| 连接成功，但助手没用ChanCharts | 确认对话已启用该连接，并明确说“请使用ChanCharts查询”。 |
| 免费次数用完 | 打开升级页；不需要删除连接或重新授权。 |
| 自选股或完整复盘提示权限不足 | 普通分析与这些功能权限不同，先直接指定股票分析，或核对相应权益。 |
| 提示请求太频繁 | 按提示等待后再试，不要连续点击连接或反复提交。 |
| 授权过期或已撤销 | 平时客户端会自动续期；确实要求重新授权时，再按提示操作。重新授权不会重置体验次数。 |
| 数据暂不可用 | 记录股票、时间和错误提示，稍后再试或联系支持，不要要求助手用猜测替代。 |

联系支持时，提供连接名称、操作时间、股票名称或代码、错误提示，以及结果中的请求编号（如有）即可。截图请遮住个人信息，**不要发送 Token、Cookie、完整邀请码或其他登录凭据**。

## 10. 常用入口

- [ChanCharts 网站](https://chancharts.com/)：查看网站提供的图表和研究功能，具体以当前账号权限为准。
- [MCP会员升级与激活](https://chancharts.com/mcp/upgrade)：查看后续权益及激活说明。
- WorkBuddy中填写的服务地址：`https://mcp.chancharts.com/mcp`。请复制到连接配置中，不要当作网页入口点击。

ChanCharts 帮你整理研究依据，最终判断仍由你自己作出。分析和报告仅供学习、研究与复盘参考，不承诺收益。
